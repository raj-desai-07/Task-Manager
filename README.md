# Task Manager – CRUD Based Application

Task Manager is a simple web-based application designed to help users manage their daily tasks efficiently. The project focuses on core CRUD operations and basic user account management using a clean and structured workflow.

---

## Project Overview

This application is built with a single user-side interface. Users can register, log in, and manage their tasks by creating, viewing, updating, and deleting them. The project uses Django’s default admin panel only for backend management, without a custom admin dashboard.

---

## User Functionalities

- User registration and login  
- Secure user authentication  
- Create tasks  
- View task list  
- Update existing tasks  
- Delete tasks  
- Change password  
- Delete user account  
- Logout functionality  

---

## Key Features

- User Authentication and Authorization  
- CRUD Operations (Create, Read, Update, Delete)  
- Relational Data Management  
- Session Management  
- Form Validation and Error Handling  
- Clean User Interface and Data Flow  

---

## Technologies Used

- Frontend: HTML, CSS, JavaScript, Bootstrap  
- Backend: Python, Django
